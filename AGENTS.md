# Agent instructions

Before making any change in this repository, read
[docs/agent-coordination.md](docs/agent-coordination.md). It lists work in
progress, decisions, open items and the shared log between Codex and Claude.
Update it in the same pull request as your change.

Also follow [CONTRIBUTING.md](CONTRIBUTING.md) and [SECURITY.md](SECURITY.md).
This repository is public: never commit patient data, credentials or hospital
captures. Every merge to `main` deploys the public site.
